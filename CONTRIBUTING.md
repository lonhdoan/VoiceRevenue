# Contributing

Contributions are welcome under the MIT License.

Principles:
- Keep core features usable without paid APIs or subscriptions.
- Prefer Apple native frameworks and deterministic local logic.
- Do not add analytics, ads, tracking, or maintainer-controlled servers.
- New parser rules must include deterministic unit tests.
- Never commit secrets, API keys, service-account files, or personal transaction data.
- Keep iOS 15 compatibility unless a major version explicitly changes the baseline.
